# Phase 2 — 첫 학습, 그리고 손실 배선 오류 3건

**기간** 2026-08-28 ~ 08-30  **결과** 4.099 → 재배선 후 3.858. 앞선 5개 런 전량 폐기

---

## 문제

구현을 끝내고 첫 본 학습(`meta` = 논문 M+R)을 돌렸다. **4.099** — 목표 3.683 에
0.42 뒤졌다. 축을 하나씩 붙여도 좀처럼 안 좁혀졌다.

그리고 학습 로그에 이상한 값이 계속 찍혔다.

```
epoch  1  lrr_fwpdc 4037.8
epoch 14  lrr_fwpdc 4002.0     ← 7만 step 동안 평평
```

## 가설

`lrr` 손실이 안 줄어드는 건 **헤드가 학습되지 않고 있다**는 뜻이다. 후보 둘:

| 가설 | 판별법 |
|---|---|
| A. 좌표 스케일 문제 (픽셀 0~120 이라 손실이 4,000) | 좌표를 [0,1] 로 정규화해 본다 |
| B. 손실 결합 방식 문제 | gradient 를 직접 재 본다 |

## 실험

**① 헤드가 정말 죽었는지** — 체크포인트를 열었다

```
fc_lm 출력   범위 [ 0.09,   0.60]     ← 사실상 0
GT 랜드마크  범위 [12.75, 105.08]
lrr(MSE) 4248 ≈ mean(GT²)             ← 아무것도 안 배웠다
```

**② 가설 A 검증** — 좌표를 [0,1] 로 정규화하고 gradient 를 쟀다

→ **gradient 비가 정확히 1.0. 가설 A 는 틀렸다.**
`d/dp[(|main|/|aux|)·aux]` 에서 s² 와 1/s² 가 상쇄된다. `balanced()` 는 **스케일 불변**이다.

**③ 가설 B** — 논문 식 자체를 다시 봤다

```
L = L_main + (|l_main| / |l_aux|) · L_aux        ← 논문 Algorithm 1
```

비율이 **1/|aux|** 다. **보조항 오차가 클수록 gradient 가 작아진다** — 목표에서 먼
헤드일수록 덜 배운다. fWPDC 0.06 / lrr 4248 이라 비율이 1.5e-5 까지 떨어졌다.

## 결과 — 더 큰 것 3건이 딸려 나왔다

lrr 을 고치고 손실 결합 전체를 다시 봤더니 **세 군데가 더 어긋나 있었다.**

**① Wing 이중 스케일** — `SynergyLoss` 가 Wing 을 ω=10 으로 나눠 놓고, 가중치는
*나누지 않은* Wing 기준 비율(2.5)을 그대로 곱했다. 랜드마크:파라미터 기여가
원본 13.92:1 인데 **1.39:1** — SynergyNet 의 핵심 감독이 10배 약한 채로 돌았다.

**② 주손실이 1.6%** — fWPDC 1.6% + lrr 0.1%. meta-joint·fWPDC·lrr 은 3DDFA_V2
기여의 전부인데 합쳐서 1.7%. 2배 연산을 치르고 1.6% 짜리 항을 경쟁시킨 셈이다.

**③ `normalize_aux` 가 항의 개수만 봤다** — `1/(1+Σw)`. 보조항이 O(0.5~5) 인데
주손실이 O(0.07) 이라 **항을 더할수록 총합이 커졌다.** 실측으로 synergy 런의 손실이
비-synergy 런의 **7.2배**. 같은 lr0 인데 gradient 가 7배 다르면 "축의 기여" 가 아니라
실효 LR 차이를 잰 것이다.

**폐기한 런** (`runs/fa3d/_archive_old_wiring/`)

| 런 | 당시 NME | 재배선 후 |
|---|---|---|
| `meta_synergy` | 3.874 | **3.858** |
| `meta_synergy_param` | 3.776 ← 당시 최고 | **3.876** ← 뒤집힘 |
| `mbv2_synergy` | 3.922 | — |
| `meta_param` | 4.127 | — |

**`param` 축의 결론이 뒤집혔다.** 구배선에서 이득(−0.098)이던 게 재배선 후 손해(+0.018).
§3.8 의 "identity 붕괴 처방" 은 실제로는 **배선 오차를 보상**하고 있었다.

## 수정

- `engine.combine(balance='share')` — 항의 **개수**가 아니라 **크기**로 맞춘다.
  보조 블록 전체를 `|main|` 기준으로 조정하므로 내부 비율(원본 절대값)은 보존된다.
  항별 기여 몫을 학습 로그에 찍는다.
- `lrr` 은 **GT 를 [0,1] 로 정규화**해 헤드가 정규화 좌표를 예측하게 했다
  (손실을 나누는 게 아니다 — 그건 스케일 불변이라 안 통한다).
- 회귀 테스트 4종이 고정한다.

## 결론

- **손실 결합은 값이 아니라 gradient 로 검증해야 한다.** 값이 균형을 이뤄도 학습은 안 될 수 있다
- 배선이 어긋나면 축 비교 자체가 성립하지 않는다. 50 epoch 짜리 런 5개를 태우고서야 발견했다
- **다음 국면**: 아직 검증 안 된 축이 하나 남았다 — 배치·LR
