# Phase 5 — 증강·svs 로 일반화 격차 메우기

**기간** 2026-08-31 ~ 09-01  **상태** ✅ **완료 — 배포 가중치를 넘겼다**

---

## 문제

Phase 4 에서 남은 격차의 정체가 **일반화**로 확정됐다.

```
300W-LP val (학습 분포)   우리 −0.097   ← 우리가 이김
AFLW2000-3D              우리 +0.138
AFLW (사람 주석 GT)        우리 +0.431   ← 크게 짐
```

그리고 구체적인 실패 유형까지 나왔다:

- AFLW 실패(NME>10%) **416장 vs 배포 178장** (2.3배)
- 우리만 실패한 252장의 유효 랜드마크 **15.8 → 11.7** = **가려진 얼굴**
- 300W-LP 에는 가림이 거의 없다 (렌더링 합성 데이터)

## 가설

**증강이 격차를 메운다.** 두 갈래가 있다:

| 갈래 | 근거 | 비용 |
|---|---|---|
| **A. svs** (논문의 S) | 배포는 M+R+**S**, 우리는 M+R. S 는 노이즈·블러·in-plane·out-of-plane = 증강이다 | 스텝당 8배 |
| **B. 색상·가림 증강** | SynergyNet 이 쓴다(`ColorJitter` + 랜덤 가림 7종). **진단된 실패 유형(가림)을 정면으로 겨냥** | 거의 무료 |

논문은 S 로 AFLW 4.50 → 4.43(−0.07)만 보고한다. 우리 AFLW 격차는 +0.431 이라
**S 만으로는 설명이 안 된다.** B 가 필요할 가능성이 크다.

## 실험

전부 `meta_paper`(b128 / lr0.02 — Phase 3 의 최고이자 논문 설정) 위에서 단일 축.

| # | 프리셋 | 추가한 것 | 겨냥 |
|---|---|---|---|
| 1 | `meta_paper_aug` | color 0.4 · 가림 1% · 테두리 5px | SynergyNet 원본 세기 |
| 2 | `meta_paper_aug5` | 가림 **5%** | 진단된 실패 유형 직격 |
| 3 | `meta_paper_svs` | svs (n=8) | 논문의 S. 배포와 같은 조건(M+R+S) |

### ⚠ 판정 기준을 바꾼다

평균 NME 만 보면 안 된다. 일반화와 학습 도메인 성능을 **맞바꾸는** 것이므로:

| 지표 | 기대 방향 |
|---|---|
| **AFLW 실패(>10%) 수** | 416 → 178 쪽으로 **줄어야** 한다 |
| AFLW 평균 NME | 4.868 → 4.438 쪽으로 |
| **300W-LP val** | **나빠져야 정상** (우리 2.094 → 배포 2.191 쪽) |
| AFLW2000-3D p99 | 9.636 → 8.736 쪽 (꼬리가 격차의 59%) |

300W-LP val 이 그대로거나 좋아지면 **증강이 안 먹은 것**이다.

> ### ⚠ 이 절의 값은 **두 번 정정됐다**
>

> 비율로 보니 전 점이 균일하게 나빴다. 절대 오차가 큰 부위가 자동으로 상위에 온다.
> **부위 비교는 반드시 비율로.**
>
> **오류 2 — `error_analysis.py` 가 테두리 전처리를 안 넘겼다.** `meta_paper_aug` 는
> `aug_border=5` 로 학습했는데 평가에서 안 걸어, 학습·평가 불일치를 **분석 스크립트에서
> 재현**했다(`_invalid_aug_traintest_mismatch` 런과 같은 실수). 3.688 을 3.948 로 잘못 쟀다.
> → `predict(..., border=)` 를 체크포인트 config 에서 받도록 고쳤다. 아래는 재측정값이다.
>
> **오류 3 — 두 벤치마크의 크롭이 다른데 좌표를 왕복시켰다.** AFLW2000-3D 와 AFLW 는

## 중간 결론 — 문제가 둘로 갈렸다

Phase 4 에서는 "일반화 문제" 하나로 봤는데, `aug` 결과가 **둘로 쪼갰다.**

| | AFLW2000-3D | AFLW |
|---|---|---|

**증강과 순환이 서로 다른 벤치마크를 고친다.**

| 축 | shape std | AFLW2000-3D | AFLW |
|---|---|---|---|
| 증강 | 0.657 → **0.588** ↓ | −0.105 ✅ | −0.007 |
| 순환 | 0.657 → **1.254** ↑ | −0.242 | **−0.390** ✅ |

처음엔 두 벤치마크의 GT 출처 차이(주석 규약)를 의심했으나 **편향/산포 분해로 기각**됐다 —
편향은 두 모델이 공유한다.

남은 설명은 **identity(shape) 미학습**이다. shape std 를 올린 기법만 AFLW 를 고쳤다.
인과는 아니지만 두 데이터가 같은 방향을 가리킨다 → `meta_paper_aug_synergy` 로 간다.

⚠ 다만 증강이 shape 를 **누르는** 쪽이라 두 축이 상쇄될 수 있다. 그래서
`meta_paper_synergy`(순환 단독, b128)를 함께 돌려 갈라낸다.

1. **AFLW 는 여전히 0.485 뒤진다** (5.085 vs 4.600). 증강·순환 어느 쪽도 이걸
   충분히 고치지 못했다. Phase 4 의 진단(사람 주석 GT 와의 규약 격차)이 남아 있다.

   3.793 대비 −0.035 뿐이다. b256 에서 본 −0.241(4.099→3.858)의 상당 부분이
   **배치 효과였다** — Phase 3 의 경고가 다시 확인됐다.
3. **중간 판정을 했으면 틀렸다.** ep19~30 구간에 대조군에 최대 +0.477 뒤졌고,
   그때 "순환은 후반에 밀린다" 고 진단했다. 후반에 뒤집혔다.
