# Phase 4 — 남은 격차의 정체는 일반화였다

**기간** 2026-08-31  **결과** 학습 도메인에서는 **우리가 이긴다**. 최적화 문제가 아니다

---

## 문제

Phase 3 까지 와서 3.793 vs 배포 3.683 — **0.11 부족.**

여기서 축을 더 붙이는 건 위험하다. 무엇이 부족한지 모르는 채로 손실을 더 넣거나
백본을 바꾸면 우연히 맞을 때까지 헤매게 된다. **어디서 지는지부터 재기로 했다.**

## 가설

세 가지가 가능하다.

| 가설 | 예측 |
|---|---|
| A. 최적화 부족 (손실 구현·수렴) | 학습 도메인에서도 진다 |
| B. 학습 부족 (epoch·LR) | 곡선이 아직 내려가는 중이다 |
| C. 일반화 부족 (과적합) | 학습 도메인에선 이기고 테스트에서만 진다 |

**가르는 법: 같은 두 모델을 세 도메인에서 재면 된다.**

## 실험

**① 샘플 단위 오차 분해** — 평균 하나로는 "어디서" 를 알 수 없다

**② 세 도메인 비교** — 도메인 거리에 따라 격차가 어떻게 변하는가

| 도메인 | 성격 |
|---|---|
| 300W-LP val (51,602장) | **학습 분포**. 합성 (실사진 3,837장을 face profiling 으로 부풀림) |
| AFLW2000-3D (2,000장) | GT 가 3DMM 피팅(Landmarks Marching) 유래 |
| AFLW (21,080장) | GT 가 **사람이 손으로 찍은 21점** |

## 결과

**★ 학습 도메인에서는 우리가 이긴다**

| 300W-LP val | 평균 NME | 중앙값 | p99 | 실패(>10%) |
|---|---|---|---|---|
| **우리** | **2.094** | 1.876 | **5.716** | **68** |
| 배포 | 2.191 | 1.601 | 11.527 | **632** |

배포는 실패가 **632장(우리의 9배)** 인데도 실제 데이터에선 더 낫다.

**도메인 거리에 비례해 격차가 뒤집히고 커진다**

```
300W-LP val   (학습 분포, 합성)        우리 −0.097   ← 우리가 이김
AFLW2000-3D   (3DMM 유래 GT)          우리 +0.138
AFLW          (사람 주석 GT)           우리 +0.431   ← 크게 짐
```

→ **가설 C 확정.** A 는 틀렸다(목적함수를 우리가 더 잘 줄였다).
B 도 틀렸다(Phase 3 에서 수렴 확인).

**AFLW2000-3D — 사실상 대등하다**

| | 평균 | 중앙값 | p90 | p99 | 실패 |
|---|---|---|---|---|---|
| 우리 | 3.393 | 2.941 | **4.919** | 9.636 | 18 |
| 배포 | 3.255 | 2.866 | 5.031 | 8.736 | 14 |

p90 에서는 우리가 낫다. **평균 격차의 59% 를 상위 1%(20장)가 만든다** — 꼬리 문제다.

**부위별 — identity 가 만드는 곳에서만 진다**

| 부위 | 우리 | 배포 | 차이 |
|---|---|---|---|
| 윤곽(턱선) | 5.203 | 5.168 | **+0.035** ← 대등 |
| 입 | 2.645 | 2.589 | **+0.056** ← 대등 |
| 코 | 2.112 | 1.950 | +0.162 |
| 눈 | 2.680 | 2.421 | +0.259 |
| **눈썹** | 3.820 | 3.506 | **+0.313** ← 최대 |

자세(T)가 지배하는 윤곽·입은 따라잡았고, 개인차(shape)가 지배하는 이목구비에서 진다.

**AFLW — 실패가 2.3배**

| | 평균 | p99 | 실패(>10%) |
|---|---|---|---|
| 우리 | 4.868 | **16.408** | **416** |
| 배포 | 4.438 | 9.302 | **178** |

우리만 실패한 252장의 성격:

```
주석된 21점 중 유효 수   전체 15.8  →  우리만 실패 11.7   ← 가려진 얼굴
크롭 크기               전체 275px →              263px   ← 크기는 무관
```

**가림에서 무너진다.** 자세보다 가림이 결정적이다.

**예측 파라미터 분산 — shape 가 눌려 있다**

블록별 std (샘플 축, 물리 단위):

| 모델 | pose(12) | **shape(40)** | exp(10) | shape 비 |
|---|---|---|---|---|
| 300W-LP GT | 4.36 | 75,744 | 0.559 | 2.24 |
| `meta_synergy` | 3.98 | 42,349 | 0.402 | **1.25** |
| 배포 mb1 | 2.39 | 33,777 | 0.362 | 1.00 |
| **`meta_paper`** (최고) | 3.87 | **22,196** | 0.288 | **0.66** |

현재 최고 모델의 shape 분산이 배포의 66% — 얼굴이 누구든 **평균 얼굴에 가깝게**
예측하고 자세만 맞춘다. 위의 "이목구비에서만 진다" 와 정확히 맞물린다.

> ⚠ 이 지표는 **샘플 축 std** 로 재야 한다. `sqrt(mean(값²))` 로 재면 shape 계수의
> 평균 오프셋(22,482)이 분산 차이를 덮어 0.975 로 나온다 — 한 번 이렇게 잘못 쟀다.

> ⚠ `ParamLoss` docstring 이 인용하는 `meta_synergy` 13,370(배포의 40%)은
> **구배선 값**이다. 재배선 후 42,349(125%)로 뒤집혔다. Phase 2 의 Wing 이중 스케일이
> 랜드마크 감독을 10배 눌렀던 게 identity 붕괴의 원인이었다.
> `param` 축이 재배선 후 손해로 바뀐 것도 이걸로 설명된다.

## 결론

**최적화가 아니라 일반화 문제다.**

- 300W-LP 는 실사진 3,837장을 face profiling 으로 부풀린 **합성** 데이터다.
  우리는 여기에 너무 잘 맞췄고 합성 아티팩트까지 배웠다
- **우리 학습에는 증강이 하나도 없었다.** 배치·손실·순환·백본을 다 만졌는데
  정작 일반화를 만드는 축을 안 건드렸다
- 배포는 M+R+**S** 인데 우리는 M+R 이다. 그리고 **S(short-video-synthesis)는
  본질적으로 증강**이다 — 노이즈·모션블러·in-plane·out-of-plane

**다음 국면**: 증강과 svs. 그리고 **판정 기준을 바꾼다** —
평균 NME 만 보면 안 되고, AFLW 실패 수와 300W-LP val 의 **악화**를 함께 본다
(악화되어야 정상이다. 일반화와 맞바꾸는 것이므로).
