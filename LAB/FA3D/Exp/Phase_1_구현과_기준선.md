# Phase 1 — 구현과 기준선 확보

**기간** 2026-08-27  **결과** 학습부 전체 구현, 배포 가중치 3.683 재현

---

## 문제

3DDFA_V2(ECCV 2020)를 학습시키고 싶은데 **저자가 학습 코드를 공개하지 않았다.**
`train`/`loss`/`dataset`/`optimizer` 를 전부 grep 해도 하나도 없다.

그리고 단순 누락이 아니다. 배포 체크포인트를 열면:

```
module.fc_param.weight  [62, 1024]     ← 로더가 fc 로 이름 바꿔 싣는다
module.fc_lm.weight     [136, 1024]    ← 로더가 그냥 버린다
```

`fc_lm` 은 논문 2.3절 landmark-regression regularization 의 보조 헤드다.
**저자가 논문 기여 중 하나를 코드에서 빼고 배포했다.**

## 가설

논문 본문 + supplementary 의 수식만으로 학습부를 재구현할 수 있다.
전작 3DDFA(v1)가 학습 코드를 공개했으므로 텐서 처리 방식은 참조할 수 있다.

**막힐 수 있는 지점**
1. v1 의 3DMM basis 와 V2 의 `bfm_noneck_v3` 가 다른 파라미터 공간이면 GT 를 못 쓴다
2. 논문이 안 밝힌 하이퍼파라미터(LR·epoch)가 결과를 좌우할 수 있다

## 실험

**① 파라미터 공간이 같은가**

같은 62-d 를 두 basis 로 디코딩해 68 랜드마크를 비교했다.

| | 정점 수 | keypoints 인덱스 |
|---|---|---|
| v1 basis | 53,215 | 서로 다름 |
| V2 `bfm_noneck_v3` | 38,365 | (재색인됨) |

→ **68 랜드마크 평균 절대차 0.0021 px.** 목 정점만 빼고 재색인한 것이고
파라미터 공간은 동일하다. v1 의 300W-LP GT 를 그대로 쓸 수 있다.

**② 평가 파이프라인이 맞는가** — 배포 가중치로 재현되는지 확인

| 항목 | 결과 |
|---|---|
| whitening 통계 | V2 → 3.683 / v1 → **23.541** → V2 가 맞음 |
| 크롭 규약 | 저장 roi_box vs `parse_roi_box_from_landmark` **0.58 px (0.2%)** |
| y 좌표 변환 | V2 방식(`x−1`, `size−y`) 3.683 < v1 방식 3.845 |

**③ fWPDC 가 원본 WPDC 와 같은가** — 논문 Algorithm 2 의 핵심 주장

원본 WPDC(62회 정점 재구성)를 참조 구현으로 두고 대조했다.

## 결과

**기준선 확보**

| | AFLW2000-3D | AFLW |
|---|---|---|
| 배포 mb1 | **3.683** | **4.600** |
| 배포 mb05 | 3.798 | 4.738 |
| 논문 M+R | 3.59 | 4.50 |

배포 가중치가 논문(3.59)보다 +0.09 나쁘다. 두 벤치마크에서 오프셋이 일관되므로
**배포본은 논문 best 체크포인트가 아니다.** 재현 목표는 3.683 으로 잡는다.

**fWPDC 검증 — 논문 주장 확인**

| 실제 300W-LP GT 기준 | |
|---|---|
| 가중치 상관 | **1.0000000** |
| 손실 차이 | **0.000%** |
| batch 128 속도 | fWPDC **2.73 ms** vs WPDC 278.40 ms (논문 3.6 / 41.7) |

**구현하며 잡은 것 4가지**

1. **fWPDC 축 버그** — `w_T(:,i)` 에서 T 의 **열** i 가 S 의 **행** i 와 짝인데
   행 축에 브로드캐스트해 상관이 0.94 로 떨어졌다. 값이 그럴듯해 눈으로는 못 잡는다
2. **gradient clipping 이 필수** — 논문에 없다. VDC 를 스크래치로 돌리면 2 스텝 만에
   inf (grad norm 2.6e4 → 6.3e10 → nan)
3. **v1 의 `magic_number = 0.00057339936` 정체** — 300W-LP 636,252장의 평균 스케일 f
   (실측 0.00057356106, 차이 1.6e-7)
4. **shape/exp 기저의 규약이 다르다** — shape 는 단위벡터·계수가 거대, exp 는 반대.
   계수만 보면 6자리 차이인데 실제 정점 기여도는 같은 자릿수. fWPDC 의 `‖A(:,i)‖`
   항이 이걸 흡수한다
