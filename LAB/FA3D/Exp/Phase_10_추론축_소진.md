# Phase 10 — 추론 단계 축을 다 써 봤다: 차이는 가중치 안에 있다

**기간** 2026-09-01 ~ 09-02  **상태** ✅ **8개 축 기각** · `x32` 재개로 이행

---

## 문제

AFLW 격차 **+0.485** (5.085 vs 배포 4.600)의 원인을 Phase 8~9 에서 가림(60%) ·
identity(40%) 로 나눴다. 그 두 처방을 돌렸는데 **둘 다 실패했다.**

| 처방 | 결과 |
|---|---|
| `aug_erase` p=0.5 | ❌ AFLW **+0.088 악화** · 형상 26%→23% |
| `aug_erase` p=0.2 | ⚠ −0.006 — **잡음 수준** |
| `idcons` (자세 간 일관성) | ❌ 형상 설명분산 **26% → 8%** 붕괴 |

그래서 **처방을 더 세우기 전에 "무엇이 원인이 아닌지"를 확정**하기로 했다.

## 실험 — 재학습 없이 확인 가능한 축부터

### ① 형상 축소 계수 — ❌

Phase 7 이 "가장 싼 처방" 이라 한 것 (방향 cos +0.511 은 좋은데 크기 1.114 가 과하니
스칼라 k 만 곱하면 상대오차 1.091 → 0.86).

| k | AFLW2000-3D | AFLW |
|---:|---:|---:|
| **1.00** | **3.657** | **5.085** |
| 0.50 | 3.713 | 5.148 |
| 0.00 (평균얼굴) | 3.860 | 5.271 |

**전 지표 단조 악화.** 형상 상대오차와 랜드마크 오차는 같은 것을 재지 않는다 —
상대오차는 "편차 벡터가 GT 편차에 얼마나 가까운가" 인데, 랜드마크 오차는 **편차를
안 내면 그만큼 정보를 잃는다.**

### ② 저해상도 크롭 — ❌

최악 50장 그림이 초근접이라 "원본 얼굴이 작아 업스케일된 것" 이라 적었었다. 틀렸다.

| | 크롭 박스 중앙값 | <60px 비율 |
|---|---:|---:|
| 우리만 실패(233장) | **262px** | **0.0%** |
| 둘 다 실패(160장) | 246px | 0.6% |
| 전체 | 278px | 0.0% |

**저해상도가 아니다.** 화면에 크게 보인 건 얼굴이 프레임을 채운 것이다.

### ③ 크롭 지터 부족 — ❌

| | 얼굴폭/크롭폭 중앙 | std | 중심 오프셋 std |
|---|---:|---:|---:|
| AFLW2000-3D (평가) | 0.706 | 0.039 | 0.005 / 0.007 |
| **300W-LP (학습)** | 0.675 | **0.047** | **0.022 / 0.023** |

**학습셋 변동이 평가셋보다 크다.** 크롭 지터 증강을 넣을 근거가 없다 — 이미 겪었다.

### ③-b 가림 증강 확률 낮추기 (`meta_paper_aug_synergy_erase02`) — ⚠ 잡음

p=0.5 가 깨끗한 얼굴까지 −0.085 깎았으니 확률이 과했다는 가설. 면적·조각은 그대로 두고
**확률만 0.5 → 0.2** 로 낮췄다.

```
p = 0.0   AFLW 5.085   (대조군)
p = 0.2   AFLW 5.079   ← 최소
p = 0.5   AFLW 5.173
```

**−0.006 은 잡음이다.** 근거:

- 나빠진 3,308장과 좋아진 3,054장이 **통계적으로 구별되지 않는다**
  (주석 14.2 vs 14.1 · \|yaw\| 43° vs 43°)
- 실패(NME>10%) 장수가 392 vs 대조군 393 으로 같다
- 판정 기준(가림 구간별)으로도 심한 가림만 +0.175, 나머지 두 구간은 −0.013 / −0.029

`scripts/FA3D/diff_grid.py` 로 **축이 바꾼 표본**을 직접 봤다
(`docs/FA3D/erase02_diff.jpg`) — 좋아진 것도 나빠진 것도 극단 자세·가림으로 성격이 같고,
🟢(erase02)와 🔵(대조군)가 서로 **다른 엉뚱한 곳**에 있다. 개선이 아니라
**두 모델이 무작위로 다르게 실패하는 것의 합**이다.

⚠ `pred_grid.py --mode worst` 는 이 판정에 못 쓴다 — 최악 50장은 두 모델이 **똑같이**
실패하는 크롭·자세 파탄이다 (배포 337% vs 우리 362%).

### ④ 크롭 스케일 계통 편향 — ❌

중앙값이 0.675 → 0.706 으로 4.6% 어긋나 있어, 평가 시 스케일만 스윕했다
(k>1 = 더 넓은 크롭).

| k | AFLW2000-3D 우리 | 배포 | AFLW 우리 | 배포 | 격차 |
|---:|---:|---:|---:|---:|---:|
| 0.97 | **3.644** | 3.697 | 5.105 | 4.612 | +0.494 |
| **1.00** | 3.657 | **3.683** | 5.085 | **4.600** | +0.485 |
| 1.03 | 3.688 | 3.743 | **5.077** | 4.647 | **+0.430** |

- **효과가 작다** — 최대 −0.013 (0.4%)
- **두 데이터셋의 최적 k 가 다르다** (0.97 vs 1.03) → 계통 편향이 아니라 잡음
- **방향이 가설과 반대다** — 학습 얼굴이 더 작으니 k>1 을 선호해야 하는데 반대
- k=1.03 에서 격차가 0.055 주는 건 **배포가 더 크게 나빠져서**다 (4.600 → 4.647).
  우리는 0.008 좋아졌을 뿐 — **격차 축소를 성능 개선으로 읽으면 안 된다.**

## ⚠ 이 국면에서 내가 한 잘못된 추론

### "86%는 못 맞출 이유가 없다" — 근거 없는 주장이었다

우리만 실패한 233장을 놓고 이렇게 썼다:

```
1. "원리상 불가능" 후보를 두 개 떠올렸다 (|yaw|>90, 저해상도)
2. 그게 14% 였다
3. -> "나머지 86%는 못 맞출 이유가 없다"
```

**이유를 두 개밖에 못 떠올린 것을 "이유가 없다" 로 바꿔 말했다.** 없는 것을 증명한 게
아니라 안 찾아본 것이다. 모션블러·극단 조명·주석 오류는 세지도 않았다. 그리고
"못 맞출 이유가 없다" 는 표현 자체가 **결론을 전제에 심는다.**

**제대로 된 근거는 배포의 여유였다** — 그 233장은 정의상 배포가 맞춘 표본이다:

| 배포 NME | 장수 | |
|---|---:|---:|
| 0~4% | 10 | 4.3% |
| 4~6% | 54 | 23.2% |
| 6~8% | 102 | 43.8% |
| 8~10% | 67 | 28.8% |

**여유 있게(<6%) 맞춘 건 64장(27%)뿐이다.** 67장(29%)은 배포도 8~10% 로 임계
근처라 **내가 정한 10% 커트가 만든 착시**일 수 있다. 233 이라는 숫자를 과대 해석했다.

## 결론

| 후보 | 판정 |
|---|---|
| 가림 증강 (p=0.5 / p=0.2) | ❌ 악화 / 잡음 |
| identity 일관성 (`idcons`) | ❌ 형상 붕괴 |
| 형상 축소 계수 | ❌ 단조 악화 |
| 저해상도 크롭 | ❌ 실패 표본도 262px 정상 |
| 크롭 지터 부족 | ❌ 학습셋 변동이 더 크다 |
| 크롭 스케일 계통 편향 | ❌ −0.013, 방향 불일치 |
| 주석 규약 천장 (Phase 4) | ❌ 두 모델 공통 — 차이를 설명 못 한다 |
| 자세 (Phase 8) | ❌ 가림과 얽혀 있을 뿐 |

**추론 단계에서 고칠 수 있는 것은 다 해봤고 전부 잡음 수준이다.
차이는 가중치 안에 있다.**

## 다음 — 되짚어야 할 것

증강 축을 쫓느라 **더 근본적인 미해결을 미뤄 뒀다.**

```
논문 M+R (증강·순환 없음)   3.590
우리 meta_paper (같은 조건)  3.793      +0.203
```

**같은 조건에서 재현 자체가 안 됐다.** 3.657 은 논문에 없는 두 축(증강·순환)을
얹어서 온 자리이고, 배포(3.683)만 기준으로 "넘었다" 고 말해 온 것이 이 격차를 덮었다.

남은 후보 둘 다 **아직 판정 못 했다**:

| 축 | 상태 | 크기 |
|---|---|---|
| **학습 데이터 배수** (`meta_paper_x32`) | 28/50 중단 | 우리 636,252 vs 논문 122,450 = **5.6배** |
| **svs** (논문의 S) | 13/50 · 11/50 두 번 중단 | 논문 ablation 3.59 → 3.51 |

→ **`meta_paper_x32` 를 28 epoch 부터 재개해 완주시킨다.** 중단 시점(28ep)에
`meta_paper` 대비 3.984 vs 4.042 로 앞서 있었다 — 그 자체가 "과잉 증강이 해롭다" 의
방증일 수 있는데 판정을 미뤄 뒀다.

⚠ 재개 안전성 확인 — 중단 이후 추가된 config 는 `aug_erase*` · `id_*` · `idw_gamma`
뿐이고 **전부 꺼진 기본값**이다. 학습 조건이 같다.
