# Phase 8 — AFLW 격차의 정체: 자세가 아니라 가림

**기간** 2026-09-01  **상태** ⚠ **처방 실패 — 재편** (`erase02` 로 용량 반응)

---

## 문제

Phase 5 에서 AFLW2000-3D 는 배포를 넘겼다(3.657 vs 3.683). 그런데 **AFLW 는 여전히
0.485 뒤진다**(5.085 vs 4.600). 지금까지 이 격차를 파라미터 공간에서만 봤다 —
**실제 예측 결과를 본 적이 없다.**

## 가설

Phase 4~5 에서 나온 후보들:

| # | 가설 | |
|---|---|---|
| A | **자세** — 옆얼굴에서 무너진다 | 절대 오차는 옆얼굴이 크다는 관측이 있었다 |
| B | **가림** — 300W-LP 는 렌더링 합성이라 가림이 없다 | Phase 5 에서 제기했지만 정량화 못 했다 |
| C | **크롭 규약** — AFLW 의 크롭 박스가 학습 분포와 다르다 | 미확인 |
| D | **주석 규약** — 사람 주석 21점과 3DMM 이 다른 것을 가리킨다 | Phase 4 의 천장 2.717 |

A 와 B 는 **강하게 얽혀 있다** — 옆얼굴일수록 가려진다. 갈라야 한다.

## 실험

`meta_paper_aug_synergy`(현재 최고) vs 배포 mb1, AFLW 21,080장 전수.
**가림의 대리 지표는 주석된 점 수**다 — AFLW 는 가려진 점을 `-1` 로 표시한다.

## 결과

### ① 가림이 격차를 6.8배로 벌린다

| 주석된 점 수 | 장수 | 우리 | 배포 | 차이 |
|---|---:|---:|---:|---:|
| 0~9 (심한 가림) | 1,056 | 7.049 | 5.754 | **+1.295** |
| 10~14 | 6,869 | 5.317 | 4.742 | +0.575 |
| 15~18 | 6,127 | 4.408 | 4.081 | +0.327 |
| 19~21 (거의 다 보임) | 7,028 | 4.444 | 4.253 | **+0.191** |

⚠ **"얼굴이 다 보이면 배포와 거의 같다" 고 썼는데 과했다.** +0.191 은 표본의
33.3%(7,028장)에 걸리는 실질적 격차다. 반사실로 재면 **가림이 설명하는 몫은 60%** 이고
나머지 40% 는 가림으로 설명 안 된다 — [Phase 9](Phase_9_identity_일관성.md).

### ② 자세와의 교란을 갈랐다 — 가림이 원인이다

상관(주석점 수, |yaw|) = **−0.771** 로 강하게 얽혀 있다. 교차하면:

**yaw 고정 · 가림만 변화** (차이 = 우리 − 배포)

| | 0~14점 | 15~21점 | 배수 |
|---|---:|---:|---:|
| [0,30] | +0.671 | +0.212 | **3.2×** |
| [30,60] | +0.777 | +0.427 | 1.8× |
| [60,90] | +0.498 | +0.037 | **13×** |

**모든 자세 구간에서 가림이 격차를 키운다.**

**가림 고정 · 자세만 변화** — 단조롭지 않다. 0~14점에서 [60,90] 은 +0.498 로
[30,60] 의 +0.777 보다 **오히려 작다.**

→ **가설 B 채택, 가설 A 기각.** 자세는 가림과 얽혀 있을 뿐이다.

### ③ 크롭 규약은 무죄 (가설 C 기각)

- GT 68점이 크롭 밖으로 나가는 표본 **0장**
- 얼굴/크롭 크기비 중앙값 **0.70**, p05 0.56 ~ p95 0.71 로 일정

최악 50장이 초근접으로 보이는 것은 **원본 얼굴이 작아 업스케일된 것**이지 크롭이
깨진 게 아니다.

### ④ 예상 못 한 것 — |yaw| > 90° 가 3.8% 있다

| | 장수 | 우리 | 배포 | 차이 |
|---|---:|---:|---:|---:|
| 90~120° | 803 | 6.762 | 5.772 | +0.990 |
| 120~180° | 2 | 172.755 | 175.142 | −2.387 |

**3DMM 은 원리상 뒤통수를 표현할 수 없다.** 그림(`docs/FA3D/aflw_grid_worst.jpg`)에서
먼저 눈에 띄었고 숫자로 확인했다 — 최악 표본의 제목이 `yaw +168°`, `−118°` 였다.

### ⑤ ★ 우리 가림 증강이 실제 가림과 다르다

**빈도** — `aug_occlude = 0.01`

```
한 epoch 에 가려지는 장수     6,363 / 636,252   (1%)
표본당 50 epoch 동안 평균     0.5회   → 61% 는 한 번도 안 겪는다
```

**형태** — 7종 전부 "한 조각만 남기고 나머지를 검게" 지운다

| 모드 | 지우는 면적 |
|---|---:|
| lup / rup / ldown / rdown / center | **75%** |
| lhalf / rhalf | **50%** |

**최소 절반을 날린다 — 가림이 아니라 자르기다.**

**AFLW 의 실제 가림**

| 가려진 점 비율 | 장수 | |
|---|---:|---:|
| 0~1% | 1,817 | 8.6% |
| **1~15%** | **7,269** | **34.5%** |
| 15~30% | 4,069 | 19.3% |
| 30~50% | 5,970 | 28.3% |
| 50%+ | 1,955 | 9.3% |

중앙값 **19%**. 그리고 가리는 것은 손·머리카락·안경·마이크라 **검정이 아니다.**

```
우리:  검정, 항상 50~75%, 사분면/반쪽 고정 7종, 1% 확률
실제:  임의 내용, 대개 10~30%, 임의 위치·크기, 91% 장면에 존재
```

## 해결

### 새 축 `aug_erase` — random erasing

![가림 증강 비교](../../../docs/FA3D/aug_occlusion.jpg)

기존 `_occlude`(SynergyNet 이식본)는 **지우지 않고 그대로 둔다** — 귀인을 위해
새 축을 따로 만든다.

| 파라미터 | 값 | 근거 |
|---|---|---|
| `aug_erase` | **0.5** | AFLW 는 91% 장면에 가림이 있다 |
| `aug_erase_area` | **(0.02, 0.35)** 로그균등 | 실측으로 맞춤 — 아래 |
| `aug_erase_boxes` | (1, 3) | 손·안경·머리카락이 동시에 |
| `aug_erase_fill` | `random` (단색/노이즈 반반) | 실제 가림은 검정이 아니다 |

**면적 상한은 눈대중이 아니라 실측으로 맞췄다** (덮이는 면적의 중앙값):

| 설정 | 중앙값 | 0~15% | 15~30% | 30~50% | 50%+ |
|---|---:|---:|---:|---:|---:|
| (0.02, 0.25) | 15.9% | 46.4 | 44.3 | 9.2 | 0.1 |
| **(0.02, 0.35)** ★ | **19.4%** | 37.8 | 37.6 | 23.2 | 1.5 |
| (0.03, 0.40) | 22.7% | 31.6 | 34.6 | 30.3 | 3.4 |
| **AFLW 실제** | **19.0%** | 43.1 | 19.3 | 28.3 | 9.3 |

⚠ **어림잡이다.** AFLW 의 19.0% 는 **주석점 기준**이고 이쪽은 **픽셀 면적**이다 —
다른 양의 중앙값을 맞춘 것이라 정밀한 대응이 아니다.

### 실험

**`meta_paper_aug_synergy_erase`** — 현재 최고 레시피에 **가림 축 하나만** 더한다.

```bash
FA3D_PRESET=meta_paper_aug_synergy_erase accelerate launch --num_processes 4 \
  --mixed_precision no train_fa3d.py
```

대조군은 `meta_paper_aug_synergy`(AFLW2000-3D 3.657 · AFLW 5.085).

### 판정 기준

- **주 지표 — AFLW 의 가림 구간별 격차.** 전체 평균이 아니라
  `0~9점` 구간의 +1.295 가 줄어드는지 본다. 그게 이 실험의 표적이다.
- 부수 — AFLW2000-3D 가 3.657 에서 크게 나빠지지 않아야 한다 (가림 증강이 깨끗한
  얼굴 성능을 깎을 수 있다).

## 곁가지로 고친 것

**큐 러너가 중단된 런을 처음부터 다시 돌렸다.** 우선순위가 바뀌어 도중에 끊는 일이
실제로 생겼는데(가림 축을 먼저 돌리려고 `meta_paper_svs` 를 13/50 에서 미뤘다),

## 결과 — ❌ `aug_erase`(p=0.5) 는 순증이 아니었다

### 총점

| | AFLW2000-3D | AFLW |
|---|---:|---:|
| 대조군 `meta_paper_aug_synergy` | **3.657** | **5.085** |
| + erase (p=0.5) | 3.669 | 5.173 |
| 차이 | +0.012 | **+0.088** |

### 판정 기준 — AFLW 가림 구간별 (vs 배포 mb1)

이 국면이 시작할 때 **"0~9점 구간의 +1.295 가 줄어드는지가 표적"** 이라고 적어 뒀다.

| 유효 주석점 | 장수 | 배포 | 대조군 | +erase | 개선 |
|---|---:|---:|---:|---:|---:|
| **0~9점** (심한 가림) | 1,056 | 5.754 | +1.295 | **+1.155** | **+0.140** ✅ |
| 10~14점 | 6,869 | 4.742 | +0.575 | +0.693 | −0.118 ❌ |
| 15~18점 | 6,127 | 4.081 | +0.327 | +0.409 | −0.082 ❌ |
| 19~21점 | 7,028 | 4.253 | +0.191 | +0.277 | −0.085 ❌ |

**표적은 맞혔다.** 심한 가림에서 +0.140 얻었다. 그런데 **1,056장(5%)을 얻고
20,024장(95%)을 잃었다.**

### 자세 구간별 — 옆얼굴만 좋아졌다

| AFLW2000-3D | [0,30] | [30,60] | [60,90] |
|---|---:|---:|---:|
| 대조군 | **2.885** | **3.460** | 4.625 |
| + erase | 2.942 | 3.557 | **4.509** |
| 차이 | +0.057 | +0.097 | **−0.116** ✅ |

### 형상 지표도 나빠졌다

| | 방향 cos | 크기비 | 상대오차 | 설명 분산 |
|---|---:|---:|---:|---:|
| 배포 mb1 | +0.544 | 0.860 | **0.937** | 30% |
| 대조군 | **+0.511** | 1.114 | **1.091** | **26%** |
| + erase | +0.482 | 1.099 | 1.117 | 23% |

## 왜 실패했나 (해석 — 미검증)

**가림이 전혀 없는 얼굴(19~21점)까지 −0.085 나빠진 것**이 핵심 단서다. 표적이 아닌
곳까지 깎였다는 건 **증강이 과했다**는 뜻이다. 확률 0.5 는 표본의 절반을 가리는데,
300W-LP 는 원래 가림이 없는 셋이라 그 절반이 통째로 다른 분포가 된다.

그리고 Phase 9 에서 이미 경고가 나와 있었다 — **총합 기여는 중간 가림(+0.187)이
심한 가림(+0.065)의 3배**인데, 정작 그 중간 가림이 −0.118 로 가장 크게 나빠졌다.

## 재편

| | 처방 | 상태 |
|---|---|---|
| `..._erase_hard` (더 센 가림) | ❌ **폐기** | 증거가 정확히 반대 방향이다 |
| **`..._erase02`** (확률 0.5 → 0.2) | ★ 큐 2번 | 면적·조각은 그대로 둬 확률만 격리 |

```
p = 0.0   AFLW 5.085   (대조군)
p = 0.2   ?            ← 이 사이에 이득 구간이 있는가
p = 0.5   AFLW 5.173
```

⚠ **큐 전체가 `_erase` 기반이었던 것도 문제였다.** erase 가 순증이 아니므로 기반을
`meta_paper_aug_synergy` 로 되돌리고, identity 축도 **erase 없이 단독으로**
(`meta_paper_aug_synergy_idcons`) 다시 잰다.

## 교훈

**표적 구간만 보고 성공을 선언하면 안 된다.** 판정 기준을 "0~9점 구간" 하나로 잡은 것
자체가 좁았다 — 그 구간은 전체의 5% 다. 기준에 **"나머지 95%가 나빠지지 않아야 한다"**
는 조건이 빠져 있었다.
