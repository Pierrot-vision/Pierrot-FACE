# Phase 3 — 배치·LR 축, 논문 설정이 최고였다

**기간** 2026-08-30  **결과** **3.793** (현재 최고). 배치가 단독 최대 기여 −0.306

---

## 문제

재배선 후에도 최고가 3.858 이었다. 목표 3.683 까지 0.175 남았다.

그런데 **전 런이 B=256 / lr0 0.04 였다.** 논문은 B=128 이다.

이 설정이 어디서 왔나 — Phase 2 초반에 "GPU 가 5% 밖에 안 돈다"는 이유로
처리량 최적화를 하며 정한 것이다. 배치별 샘플당 시간을 재서 골랐다:

| GPU당 배치 | ms/샘플 |
|---|---|
| 32 | 0.252 |
| **64** | **0.131** ← 최속 |
| 128 | 0.139 |
| 256 | 0.157 |

4장 × 64 = 전역 256, 선형 스케일링으로 lr 0.02 → 0.04.
**속도만 보고 정했고 정확도로는 한 번도 검증하지 않았다.**

## 가설

선형 스케일링 법칙(배치 2배 → lr 2배)이 이 태스크에서도 성립한다면
B=128 과 B=256 의 결과가 비슷해야 한다.

성립하지 않는다면 — 논문이 B=128 을 명시한 데 이유가 있는 것이다.

## 실험

`meta_paper` = `meta` 에서 **배치·LR·warmup 만** 논문 값으로 되돌린 단일 축 비교.

```python
'meta_paper': {'batch_size': 128, 'lr0': 0.02, 'warmup_epochs': 1.0}
```

나머지(손실·백본·순환 유무)는 `meta` 와 동일하다.

## 결과

| 조합 | B | lr | [0,30] | [30,60] | [60,90] | **NME** | AFLW |
|---|---|---|---|---|---|---|---|
| `meta` | 256 | 0.04 | 3.222 | 3.866 | 5.210 | 4.099 | 5.530 |
| **`meta_paper`** | **128** | **0.02** | 3.011 | 3.630 | 4.740 | **3.793** | **5.102** |
| | | | | | | **−0.306** | −0.428 |

**선형 스케일링이 성립하지 않았다.** 배치·LR 만으로 0.306 —
그때까지 잰 어떤 축보다 크다.

**축별 기여 (전부 재배선 후 동일 조건)**

```
배치·LR  b256/0.04 → b128/0.02     4.099 → 3.793   −0.306   ★ 최대
synergy 순환 (b256)                4.099 → 3.858   −0.242
백본 V1 → V2 (b256)                4.099 → 4.138   +0.039
wd 전체 적용 (b256)                 4.099 → 4.182   +0.082
+ param (b256)                     3.858 → 3.876   +0.018
```

**수렴 확인** — 학습 부족이 아니다

```
마지막 10ep 평균 3.807 · 그 앞 10ep 평균 3.871 · 최고 3.793(ep43)
```

## 결론

- **논문이 명시한 값을 바꿀 때는 정확도로도 검증해야 한다.** 처리량만 보고
  바꾼 설정이 0.306 을 먹고 있었고, 그 아래에서 잰 축들(synergy·param·백본)은
  전부 통제가 안 된 상태였다
- 다만 이걸 고쳐도 **여전히 0.11 부족하다** (3.793 vs 3.683)
- **다음 국면**: 남은 0.11 은 어디서 오나. 축을 더 붙이기 전에 원인부터 찾는다

> ⚠ 큐 스크립트가 `FA3D_OVERRIDE` 기본값으로 b256/0.04 를 강제하고 있었다.
> `${VAR:-기본}` 은 빈 문자열도 기본으로 바꾸므로 `FA3D_OVERRIDE=""` 로 꺼지지 않는다 —
> Phase 5 에서 이걸로 잘못된 배치의 런을 한 번 띄웠다. 기본값 자체를 없앴다.

**배치·LR 축 하나가 −0.306** 을 만든다 (4.099 → 3.793). 손실 설계 차이보다 크다.

`mbv2` 는 같은 배치의 `meta_b256`(4.099)보다 나쁘다(4.138) — **백본 교체는 답이 아니었다.**

⚠ 이 셋은 전부 **b256** 이라 `meta_paper`(b128)와 나란히 읽으면 안 된다.
