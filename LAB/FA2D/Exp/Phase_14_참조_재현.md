# Phase 14 — 참조 수치를 우리 손으로 재현하다

기간 09-10 ~ 09-12 · 결과 **Peppa 공개값을 0.01 이내로 재현**(Teacher 3.959 vs 3.95,
Student 4.353 vs 4.35). HRFFA 공식 교사 가중치도 확보해 다시 쟀다. 이전에 보고한
외부 모델 측정값 **4.840 · 12.489 · 4.640 · 5.004 를 전부 폐기한다.**

## 문제

"우리가 참조보다 나쁘다"고 말해 왔는데, 정작 외부 모델을 우리가 직접 재면 값이
제각각이었다 — HRFFA 4.840(공개 1.51), Peppa Student 4.886~5.16(공개 4.35).
어느 값이 맞는지 모르는 채로는 우열도, 개선 방향도 말할 수 없다.

## 가설

우리가 상대 모델의 **평가 조건**을 안 지키고 있다. 후보는 넷이다.

1. 모델 헤드 — HRFFA 공개 ONNX 는 68 점인데 공식 수치는 98 점 헤드로 냈다
2. 크롭 — 박스 출처(검출 vs 랜드마크 외삽)와 모양(정사각 vs 직사각)
3. 색 순서 — BGR/RGB
4. 정규화 — NME 를 어느 좌표계에서 재는가

## 실험 A — HRFFA 공식 체크포인트로 다시 재기

릴리스의 `clean_v3.tar.gz`(교사 학습 산출물)를 받아 `.pt` 를 우리 파이프라인에 실었다.
체크포인트에 `queries.wflw98` 가 있다 — 공식 1.513 은 **98 점 헤드** 값이다.

| 측정 | 크롭 | 점 | io-NME |
|---|---|--:|--:|
| 그들 공식 로그 (`eval_e198_official.log`) | 그들 JSONL 박스 | 98 | 1.513 |
| 우리 측정 (`.pt`, 같은 코드·같은 pad 0.05) | 랜드마크 외삽 | 98 | **1.698** |
| ~~이전 보고~~ (공개 ONNX) | 랜드마크 외삽 | 68 | ~~4.840~~ **폐기** |
| ~~이전 보고~~ (DEIMv2 검출 박스) | 검출 | 68 | ~~12.489~~ **폐기** |

같은 모델·같은 코드인데 1.513 과 1.698 이 갈리는 유일한 입력 차이는 **머리 박스**다.
그들 JSONL 박스는 공개돼 있지 않다.

## 실험 B — Peppa 공식 평가 규약 재현

그들 평가 스크립트(`tools/eval_WFLW.py`)를 읽고 세 가지를 맞췄다.

| 항목 | 그들 방식 | 우리가 쓰던 방식 |
|---|---|---|
| 크롭 | 랜드마크 박스를 가로 ×1.2 · 세로 ×1.4 로 늘린 **직사각형** → 256 정사각 리사이즈 | 긴 변 기준 정사각 ×1.1 |
| 색 순서 | `cv2.imread` 그대로 **BGR** | RGB 로 변환 |
| NME | 크롭 w·h 로 각각 나눈 좌표계 | 이미지 평면 |

| 모델 | 공개값 | 우리 재현 | 이전 보고(폐기) |
|---|--:|--:|--:|
| Peppa Teacher@256 | 3.95 | **3.959** | ~~4.640~~ |
| Peppa Student@256 | 4.35 | **4.353** | ~~5.004~~ |

**공개값은 재현된다.** 이전 격차는 전부 우리 규약 위반이었다.

## 실험 C — HRFFA 의 어려운 조건 평가를 이식

그들 `evaluate.py` 의 pose-stress(회전 360°·카메라 pitch/yaw)·style-shift(블러·색온도·
감마·흑백·JPEG)·6DRepNet 자세 층별을 WFLW test 로 옮겼다
(`scripts/FA2D/hrffa_protocol.py`, `eval_hrffa_protocol.py`). 세 모델 동일 조건.

| 조건 | HRFFA 교사 | Peppa Student | 우리 `full_v9` |
|---|--:|--:|--:|
| 기준 (pad 0.15) | 1.861 | 4.777 | 4.009 |
| 회전 180° | 1.901 | **122.079** | 4.007 |
| 카메라 pitch −25° | 1.948 | 5.900 | 4.418 |
| 전체 섭동 평균 | 1.855 | 38.872 | 4.052 |
| 모션 블러 21px | 2.404 | 7.112 | 4.309 |
| 유효 \|yaw\| 60–95° | 2.604 | 8.916 | 6.185 |

Peppa 는 회전 ±30° 만 학습해 90° 이상에서 무너진다. 우리와 HRFFA 는 360° 등변이다.

## 실험 D — 누출 확인

HRFFA 설정 파일에서 `train_all_splits: true`(`clean_v2` → `clean_v3`, 학생 전부)와
`REAL_ALL_SPLITS = {"wflw": ("train","test"), ...}` 를 확인했다. **WFLW test · 300W valid ·
COFW test 가 학습에 들어간다.** README 45 줄도 같은 내용을 적어 두었다.

학습한 이미지에서 재면 값이 얼마나 내려가는지 우리 모델로 쟀다.

| 모델 | 평가 이미지 | 그 이미지를 학습했나 | io-NME |
|---|---|:--:|--:|
| 우리 `full_v9` | WFLW train 7,500 | ✅ (약 85 회 노출) | 2.849 |
| 우리 `full_v9` | WFLW test 2,500 | ❌ | 3.980 |
| Peppa Teacher | WFLW train 7,500 | ✅ | 1.836 |
| Peppa Student | WFLW train 7,500 | ✅ | 1.754 |

## 결론

- **비교 기준이 확정됐다.** 각 모델을 자기 규약으로 재면 공개값이 재현된다.
  이후 보고는 이 값을 쓴다 — Peppa Teacher **3.959** · Student **4.353** · D-ViT 3.75(논문).
- **HRFFA 행은 전부 학습한 이미지 위의 값**이다. 순위 비교에 쓸 수 없고, 표에 학습 범위
  칸을 함께 적는다.
- 상대 모델을 잴 때는 **헤드·크롭·색 순서·정규화** 네 가지를 먼저 맞춘다. 이번에 넷 중
  셋을 틀렸다.
