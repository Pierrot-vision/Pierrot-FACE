# Phase 2 — 시간축을 사후 처리가 아니라 모델 안으로

기간 08-31 ~ 09-01 · 결과 포크 5커밋으로 검증 → Lab 재구현 2,456줄

## 문제

Peppa 의 스무딩(LK + OneEuro)을 그대로 붙이면 되는가?

## 가설

**안 된다.** 사후 필터는 참 움직임을 모르므로 "덜 움직이게" 누를 수밖에 없고,
그것이 지연이 된다. 극단 자세일수록 예측이 불안정해 떨림이 큰데, 하필 그 구간이
우리 목표다.

## 실험

합성 신호(노이즈 σ=0.8px, 60프레임)로 OneEuro 의 한계를 실측했다.

| 움직임 | 필터 없음 | OneEuro |
|---|--:|--:|
| 정지 | 0.798 | **0.309** |
| 0.1 px/frame | 0.767 | 0.434 |
| 0.5 px/frame | 0.827 | **0.927** ← 악화 |

빠른 움직임에서 지연이 노이즈 이득을 삼킨다. **원리적 한계**다.

그런데 HRFFA 의 호모그래피 증강은 **우리가 변환을 적용**하므로 참 움직임을 안다.
여기서 길이 열렸다 — 정지 이미지에서 합성 클립을 만들면 프레임 간 움직임이
정확히 알려지고, "움직임은 따라가고 노이즈만 억제하라"를 손실로 직접 걸 수 있다.

## 결과

상류 포크(`hrffa-plus` 브랜치)에서 먼저 검증한 뒤 Lab 규약으로 재구현했다.

| 확장 | 검증 |
|---|---|
| 궤적 샘플러 (합성 클립) | 프레임 간 GT 오차 **< 1e-6 px** |
| 시간축 디코더 (`prev_proj`) | zero-init → 얹은 직후 출력 동일 |
| 시간 일관성 손실 | 지연·떨림 양쪽 다 벌하는지 테스트 |
| **지터·지연 지표** | 완벽추종 lag 1.00 / 완전지연 0.00 / 노이즈만 0.96 |
| 상태 헤드 + 가시성 게이팅 | 스케일 불변 · 가려진 부위 −1 |

구현 중 실제로 잡은 것 둘.

- **궤적이 경계에 고착** — 단순 클램프는 등속 성분이 값을 경계로 밀어붙인다
  (`yaw −15.00` 고정). 속도를 반사시켜 해결.
- **`prev_proj` 에 bias 가 있으면 안 된다** — ONNX 는 선택적 입력이 어려워 첫
  프레임에 0 을 넣게 되는데, bias 가 있으면 `prev_proj(0) = bias ≠ 0` 이라 학습
  때의 `prev_tokens=None` 과 달라진다. bias 를 빼면 정확히 등가.

## 결론

- 지터 지표가 **판정 수단**이다. 없으면 시간축이 효과가 있는지 잴 수 없다.
- 판정 규칙을 **학습 전에** 못박았다: `lag_ratio` 를 유지한 채 `jitter_px` 가
  내려가야 채택. 결과를 보고 기준을 정하지 않기 위해서다.
- 이 가설의 검증은 Phase 5 로 넘어간다.
