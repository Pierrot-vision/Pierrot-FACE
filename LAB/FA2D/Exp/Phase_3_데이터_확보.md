# Phase 3 — 데이터: 공식 배포가 막혔을 때

기간 09-02 · 결과 7,500 → **25,668장**, 규약 2종

## 문제

WFLW 공식 이미지가 Google Drive 단일 링크뿐인데 할당량으로 실패했다.
주석 10,000줄은 받았지만 이미지가 없으면 아무것도 못 한다.

## 가설

WFLW 주석의 이미지 경로가 `51--Dresses/51_Dresses_wearingdress_51_377.jpg` 형태다.
**WIDER FACE 명명 규약**이다 — WFLW 가 WIDER FACE 부분집합이라면 그쪽에서 복원된다.

## 실험

주석이 참조하는 고유 이미지를 세니 **6,551장**, 60개 카테고리 디렉터리.
WIDER FACE 구조와 일치했다. 공식 배포처(CUHK)가 HF 에 있고 인증도 불필요했다.

```
WIDER_train.zip(1.4GB) + WIDER_val.zip(363MB) → 참조 6,551장 선별 복사
```

## 결과

| 소스 | 규모 | 규약 | 상태 |
|---|--:|---|---|
| WFLW | 7,500 / 2,500 | 98 | ✅ **6,551/6,551 복원 (누락 0)** |
| LaPa | 18,168 / 2,000 | **106** | ✅ HF, 2.4GB |
| 300W Challenge | 600 | 68 | ✅ **평가 전용** |
| COFW | — | 29 | ❌ 공개 소스 없음 |

**LaPa 의 flip_mapping 은 공식 문서에 없어 데이터에서 유도했다.** 틀리면 좌우가
조용히 뒤바뀐 채 학습되고 손실은 정상적으로 내려간다 — 가장 위험한 종류다.

첫 시도(최근접 매칭)는 실패(involution 불성립, 합의율 0.65). 방법을 바꿨다.

```
대칭축 스칼라 최적화 → Hungarian 최적 할당 → 상호 합의만 채택
  → involution 성립 · 합의율 0.99 · 48쌍 + 자기대응 10
```

자기대응이 `[16, 51~54, 60, 87, 93, 98, 102]` 로 **전부 중앙선 점**(윤곽 중앙·콧대·
코끝·입술 중앙)이라는 것이 구조적 방증이다. 보류 split 500장에서 미러 잔차를
**3.4배** 줄였다(0.4417 → 0.1302).

## 결론

- 공식 배포가 막혀도 **상위 데이터셋에서 재구성**할 수 있다. 검증 가능하다는
  이점도 있다 — 6,551장이 다 있는지 세면 된다.
- ⚠ **300W Challenge 를 "누수 없는 평가 축"으로 쓰려 했으나 무효였다.** 68점
  규약인데 우리 학습 데이터에 68점 소스가 하나도 없어, ibug68 쿼리가 한 번도
  감독받지 않은 랜덤 초기값이다. 그 수치(13.3)는 성능이 아니다.
- 학습 투입 차단은 코드로 걸어 뒀다(`EVAL_ONLY_SOURCES`).
