# FA2D vs FA3D — 무엇이 다른가

두 태스크는 둘 다 "얼굴에서 점을 찾는다"지만, **출발점 · 데이터 · 무엇을 기준으로 삼는가**가
전부 반대다. 수치는 각 태스크의 LAB 기록(09-16 기준)과 이 저장소의 평가 코드로 잰 값이다.

| 축 | **FA2D** — 2D 얼굴 정렬 | **FA3D** — 3D 밀집 얼굴 정렬 |
|---|---|---|
| **■ 무엇을 푸는가** | | |
| 목표 | **극단 자세**에서도 랜드마크를 잘 찾는 것 | 한 장의 사진에서 **3D 얼굴**을 복원하는 것 |
| 출력 | 2D 랜드마크 **98점** (+ 점별 가시성 · 자세) | **62-d 3DMM 파라미터** → 정점 38,365 · 68 랜드마크 |
| 좌표가 나오는 경로 | 모델이 **좌표를 직접** 낸다 | 파라미터가 **BFM 기저를 통과해** 좌표가 된다 |
| 규약 | 68 · 98 · 29 · 106 을 **한 모델**이 낸다 (규약별 쿼리) | 62-d 고정 |
| **■ 출발점** | | |
| 기반 연구 | **HRFFA** (학습 코드 공개, MIT) + **Peppa** (stride 4 히트맵) | **3DDFA_V2** — **학습 코드 없음**, 논문 수식에서 직접 구현 |
| 기준선 | 참조 연구 — **Peppa** 3.959 / 4.353 · **D-ViT** 3.75 | 저자 **배포 가중치** mb1 3.683 |
| 기준선을 그렇게 잡은 이유 | HRFFA 는 **평가셋을 학습**해 자기 수치가 벤치마크가 아니다 | 배포본을 같은 코드로 잴 수 있고, 논문 수치는 배포본도 재현 못 한다(+0.09) |
| **■ 데이터** | | |
| 학습셋 | **실사진 33,357장** — WFLW train · LaPa train+val · COFW · 300W | **합성 636,252장** — 300W-LP (얼굴 3,837개 × 179 자세) |
| 라벨 | **사람 주석** | **3DMM 피팅** (자세마다 다시 피팅해 shape 이 44% 흔들린다) |
| 평가셋 | ① WFLW test 2,500 · ② LaPa test 2,000 · ③ HRFFA 난이도 프로토콜 | AFLW2000-3D 2,000 · AFLW 21,080 |
| **■ 입력** | | |
| 크롭 | **얼굴 박스** + pad 0.05 → **448** (눈 사이 245px) | **얼굴 박스** → **120** (사전 크롭 배포본) |
| 전처리 | ImageNet 정규화 · RGB | (x−127.5)/128 · **BGR** · 테두리 5px 0 처리 |
| **■ 모델** | | |
| 구조 | 백본 → **점 쿼리 트랜스포머 디코더** | 백본 → **FC 한 층**으로 62-d 회귀 |
| 교사 · 학생 | 교사 **DINOv3 ViT-L/16 310M** · 학생 **ViT-T/16 10.5M** | **MobileNet-V1 3.27M** 단일 (교사·학생 구분 없음) |
| 좌표 정밀화 | 교사: stride 4 **국소 보정** · 학생: stride 4 **히트맵 + 오프셋** | 없음 (파라미터 회귀가 끝) |
| 학습 전용 분기 | — | 68점 회귀 헤드(lrr) · SynergyNet 순환 — **추론 비용 0** |
| **■ 학습** | | |
| 손실 | smooth-L1 + 가시성 (학생은 AWing + 오프셋 L1 추가) | **meta-joint** — VDC / fWPDC 를 스텝마다 골라 쓴다 |
| 증류 | **교사 고정(A)** 로 학생 학습 — 이득 −0.098 로 작다 · 동시 미세조정(B)은 역효과 | 쓰지 않음 |
| 증강 | roll **360°** · 카메라 pitch ±25° / yaw ±15° · 어려운 표본 가중 | 색 · 테두리 · 가림 · 실제 물체 가림 |
| 시간축(영상) | 모델 안에 이전 프레임 주입 → **기각** (지터 2배로 악화) | 짧은 영상 합성(svs) — 추론 평활은 논문이 반대 |
| **■ 평가 지표** | | |
| NME 정규화 | 눈 **바깥꼬리** 거리 (inter-ocular) | GT 랜드마크 bbox 의 √(w·h) |
| 평균 방식 | 전 표본 평균 | **yaw 3구간 평균의 평균** (단순 평균보다 0.4 큼) |
| 지표의 한계 | 규약마다 정규화가 달라 **표끼리 비교 불가** | **NME 는 사실상 자세 지표** — 3D 형상은 거의 안 잰다 |
| 잡음 폭 | 미세조정 아암 흔들림 **±0.03** | seed 3점 **2σ ±0.106** (AFLW ±0.210) |
| **■ 무엇이 들었나 (실측)** | | |
| 가장 큰 레버 | **얼굴이 차지하는 화소** — 71px → 140px 만으로 −0.79 | **증강 + 순환(synergy)** |
| 안 들은 것 | **백본 크기 0%** · 증강 범위 확대 · WSD 일정 · 시간축 | **백본 교체**(YOLO 계열 2종) · 학습 길이 · 추론 단계 축 8개 |
| flip-TTA | 4.120 → 4.078 (−1.0%, `teacher_v3` 기준) — 작아서 기본값 아님 | **채택** — 3.622 → 3.508 (−0.11) |
| **■ 현재 성적** | | |
| 우리 | 교사 **3.916** · 학생 **4.227** (WFLW) | **3.622** (AFLW2000-3D) · 5.125 (AFLW) |
| 기준선 대비 | 교사·학생 모두 **Peppa 상회** · **D-ViT 3.75 에는 뒤짐** | 배포 3.683 상회 — 단 **잡음 폭(±0.106) 안** |
| 극단 자세 | roll 최악 **3.997** vs Peppa Teacher 124.851 | 60~90° 구간이 가장 약함 · AFLW(실사진·가림) 격차 +0.525 |
| 남은 과제 | D-ViT 와의 격차 0.166 | AFLW 격차 — 원인의 60% 가 **가림** |

## 용어 설명

### 3DMM — 3D Morphable Model (3D 형태 변형 모델)

"**모든 얼굴은 평균 얼굴에 몇 가지 변형 방향을 섞은 것**"이라고 가정하는 선형 얼굴 모델이다.
여러 사람의 3D 얼굴 스캔을 모아 PCA(주성분 분석)를 돌리면, 얼굴이 서로 달라지는 주된 방향들이
뽑힌다. 어떤 얼굴이든 그 방향들의 가중합으로 근사한다.

```
S = S̄ + A_id · α_id + A_exp · α_exp
```

| 기호 | 뜻 | FA3D 에서의 크기 |
|---|---|---|
| `S̄` | 평균 얼굴 (정점 좌표) | 3 × 38,365 |
| `A_id` · `α_id` | **신원** 기저 · 계수 — 사람마다 다른 골격 (광대 · 턱 · 코 모양) | 40개 |
| `A_exp` · `α_exp` | **표정** 기저 · 계수 — 입 벌림 · 눈 감음 등 | 10개 |

FA3D 모델이 내는 **62-d** 가 바로 이 계수들이다 — 자세(회전·스케일·이동) 12개 + 신원 40개 +
표정 10개. 모델은 3D 좌표를 직접 내지 않고 **계수만** 낸다. 좌표는 위 식에 계수를 넣어 계산한다.
그래서 적은 숫자(62개)로 38,365개 정점의 매끄러운 얼굴이 나오지만, 기저가 표현하지 못하는
모양(주름 · 특이한 골격)은 원리상 복원할 수 없다.

### BFM — Basel Face Model

3DMM 의 **구체적인 한 판본**이다. 스위스 바젤 대학이 200명의 3D 스캔으로 만들어 2009년에
공개했다. 위 식의 `S̄` · `A_id` 가 여기서 온다(표정 기저 `A_exp` 는 FaceWarehouse 에서 가져와
붙인다). 원본은 정점 53,215개이고, FA3D 가 쓰는 `bfm_noneck_v3.pkl` 은 **목을 잘라낸
38,365개** 판본이다. 목을 빼도 62-d 파라미터 공간은 같다 — 같은 계수를 두 판본으로 펴면
68 랜드마크가 0.002 px 밖에 안 다르다.

원래 기저는 신원 199개 · 표정 29개인데, 뒷부분 주성분은 형상에 거의 기여하지 않아
**40 · 10 개만** 쓴다 (정확도 손실 약 0.4%, 계산은 5배 빠르다).

### VDC — Vertex Distance Cost (정점 거리 손실)

**복원한 3D 얼굴과 정답 얼굴의 정점 좌표 차이를 직접 잰다.**

```
L_vdc = ‖ V3d(예측 62-d) − V3d(정답 62-d) ‖²      (38,365 정점 전부)
```

최종 목표("얼굴이 맞는가")와 가장 가까운 손실이라 **학습 후반에 좋다.** 대신 스크래치에서는
최적화가 매우 어렵다 — 62개 파라미터 중 회전은 정점을 크게 움직이고 고차 신원 계수는 거의
안 움직여서, 기울기가 좁은 골짜기를 가로질러 진동한다(zig-zagging). 실측으로 랜덤 초기화에서
SGD 를 밟으면 **2스텝 만에 발산(inf)** 했고, 기울기 클리핑 없이는 학습이 성립하지 않는다.

### fWPDC — fast Weighted Parameter Distance Cost (빠른 가중 파라미터 거리 손실)

VDC 와 **반대 전략**이다. 정점이 아니라 **62-d 파라미터 공간에서** 오차를 재되, 파라미터마다
"그게 틀리면 얼굴이 얼마나 망가지나"로 가중을 준다.

```
L_wpdc = ‖ w · (p − p_gt) ‖²
w_i    = "i번째 파라미터만 틀리고 나머지는 정답일 때" 정점이 벗어나는 거리
```

회전이 틀리면 얼굴 전체가 돌아가니 가중이 크고, 고차 신원 계수가 틀리면 거의 안 바뀌니
가중이 작다. 파라미터 공간이라 기울기 지형이 순해서 **학습 초반에 잘 수렴**한다.

**WPDC(원본)** 는 가중 62개를 구하려고 정점 재구성을 **62번** 반복해 느리다(스텝당 41.7ms).
**fWPDC** 는 3DDFA_V2 논문의 핵심 트릭으로, 가중치를 회전 항과 계수 항으로 **분해**해 정점
재구성을 **1번**으로 줄인다. 값은 원본과 수학적으로 정확히 같다.

⚠ 부작용 — 신원 계수 40개의 가중이 회전보다 **33배** 작아서, 모델이 신원을 포기하고
평균 얼굴에 눌러앉는 경향이 생긴다. FA3D 의 NME 가 좋아도 3D 형상이 사람마다 비슷하게 나오는
원인 중 하나다.

### meta-joint optimization (메타 결합 최적화)

**VDC 와 fWPDC 중 지금 어느 손실로 학습할지를 매번 "미리 가 보고" 고르는** 방식이다
(3DDFA_V2 논문 Algorithm 1).

관찰: fWPDC 로만 학습하면 4.04, VDC 로만 하면 5.23, **fWPDC 로 학습한 뒤 VDC 로
미세조정하면 3.88.** 즉 초반엔 fWPDC, 후반엔 VDC 가 좋다. 문제는 언제 바꾸느냐다.

```
① 현재 가중치를 두 벌 복제한다
② 한 벌은 fWPDC 로, 다른 벌은 VDC 로 각자 k=100 스텝 학습한다
③ 학습에 안 쓴 배치로 두 결과를 **VDC 로** 채점한다
④ 더 나은 쪽을 다음 출발점으로 채택한다 → ① 반복
```

심판을 항상 VDC 로 두는 이유 — fWPDC 로 채점하면 fWPDC 분기가 자기 손실로 평가받아 항상
이기고, VDC 는 영원히 뽑히지 않는다. VDC 가 "실제로 얼굴이 더 맞는가"에 가장 가까운 심판이다.
대가는 학습 연산이 약 2배라는 것이다. **추론에는 아무 영향이 없다** — 학습 방식일 뿐이다.

### SynergyNet 순환 (= synergy)

SynergyNet(3DV 2021)이 3DDFA_V2 위에 얹은 **학습 전용 보조 구조**로, "3DMM 계수 ↔ 랜드마크"
사이에 **순환 고리**를 만든다.

```
사진 → 백본 → 62-d 계수 ─(BFM)→ 68 랜드마크 ─ MLP_for → 정제된 랜드마크 ─ MLP_rev → 계수를 다시 역회귀
```

| 단계 | 하는 일 |
|---|---|
| **MLP_for** (정방향) | BFM 으로 편 68 랜드마크를 PointNet 계열 MLP 가 받아 좌표 잔차를 더해 **다듬는다** |
| **MLP_rev** (역방향) | 다듬은 랜드마크에서 **3DMM 계수를 거꾸로** 회귀한다 |
| 자기일관성 손실 | 역회귀한 계수가 처음 예측한 계수와 같아지도록 벌점을 준다 |

3DDFA_V2 는 랜드마크를 보조 감독으로 **보고 버리는데**, SynergyNet 은 그 랜드마크를 **계수로
되돌려 고리를 닫는다.** BFM 디코더가 미분 가능하므로 이 고리의 기울기가 백본까지 흘러가 계수
예측을 더 일관되게 만든다. FA3D 에서 `use_synergy` / 런 이름의 `synergy` 가 이것이다.

⚠ **추론 비용은 0 이다.** 고리 전체가 학습에만 쓰이고 `predict()` 경로에 없다 — 이 저장소는
해당 모듈을 아예 만들지 않는다. 체크포인트에 남아 있는 `synergy.*` 텐서는 로드할 때 버린다.

### NME — Normalized Mean Error (정규화 평균 오차)

랜드마크 정렬의 기본 지표다. **예측 점과 정답 점의 평균 거리를 얼굴 크기로 나눈 값(%)** 이다.

```
NME = ( 1/K · Σ ‖ 예측_k − 정답_k ‖ ) / d  × 100
```

얼굴 크기 `d` 로 나누는 이유 — 같은 5 px 오차라도 큰 얼굴에선 작은 실수, 작은 얼굴에선 큰
실수다. 크기를 지워야 사진끼리 비교가 된다. **문제는 `d` 를 무엇으로 잡느냐가 문헌마다 다르고,
그에 따라 값이 통째로 바뀐다**는 것이다 — 두 태스크도 다르다.

| | FA2D | FA3D |
|---|---|---|
| `d` | **눈 바깥꼬리 사이 거리** (inter-ocular) | GT 랜드마크 박스의 **√(너비 × 높이)** |
| 그렇게 잡는 이유 | WFLW · 300W 의 표준 | 옆얼굴(yaw 90°)에서는 두 눈이 겹쳐 거리가 0 이 되고 NME 가 발산한다 |
| 평균 방식 | 전 표본 평균 | **yaw 0~30° · 30~60° · 60~90° 구간별 평균의 평균** — 정면이 많은 평가셋에서 옆얼굴 오차가 묻히지 않게 |

⚠ 그래서 **FA2D 의 3.916 과 FA3D 의 3.622 는 서로 비교할 수 없는 숫자다.** 같은 "NME" 라도
나누는 기준과 평균 방식이 다르다.

⚠ FA3D 의 NME 는 68 랜드마크의 **2D 거리**라 사실상 **자세**를 잰다 — 3D 형상(신원)을 정답으로
바꿔 넣어도 1.3% 밖에 안 좋아진다. 3D 형상이 맞는지는 `scripts/FA3D/shape_accuracy.py` 로
따로 잰다.
