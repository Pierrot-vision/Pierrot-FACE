# FA2D vs FA3D — 무엇이 다른가

두 태스크는 둘 다 "얼굴에서 점을 찾는다"지만, **출발점 · 데이터 · 무엇을 기준으로 삼는가**가
전부 반대다. 수치는 각 태스크의 LAB 기록(09-16 기준)과 이 저장소의 평가 코드로 잰 값이다.

| 축 | **FA2D** — 2D 얼굴 정렬 | **FA3D** — 3D 밀집 얼굴 정렬 |
|---|---|---|
| **■ 무엇을 푸는가** | | |
| 목표 | **극단 자세**에서도 랜드마크를 잘 찾는 것 | 한 장의 사진에서 **3D 얼굴**을 복원하는 것 |
| 출력 | 2D 랜드마크 **98점** (+ 점별 가시성 · 자세) | **62-d 3DMM 파라미터** → 정점 38,365 · 68 랜드마크 |
| 좌표가 나오는 경로 | 모델이 **좌표를 직접** 낸다 | 파라미터가 **BFM 기저를 통과해** 좌표가 된다 |
| 규약 | 68 · 98 · 29 · 106 을 **한 모델**이 낸다 (규약별 쿼리) | 62-d 고정 |
| **■ 출발점** | | |
| 기반 연구 | **HRFFA** (학습 코드 공개, MIT) + **Peppa** (stride 4 히트맵) | **3DDFA_V2** — **학습 코드 없음**, 논문 수식에서 직접 구현 |
| 기준선 | 참조 연구 — **Peppa** 3.959 / 4.353 · **D-ViT** 3.75 | 저자 **배포 가중치** mb1 3.683 |
| 기준선을 그렇게 잡은 이유 | HRFFA 는 **평가셋을 학습**해 자기 수치가 벤치마크가 아니다 | 배포본을 같은 코드로 잴 수 있고, 논문 수치는 배포본도 재현 못 한다(+0.09) |
| **■ 데이터** | | |
| 학습셋 | **실사진 33,357장** — WFLW train · LaPa train+val · COFW · 300W | **합성 636,252장** — 300W-LP (얼굴 3,837개 × 179 자세) |
| 라벨 | **사람 주석** | **3DMM 피팅** (자세마다 다시 피팅해 shape 이 44% 흔들린다) |
| 평가셋 | ① WFLW test 2,500 · ② LaPa test 2,000 · ③ HRFFA 난이도 프로토콜 | AFLW2000-3D 2,000 · AFLW 21,080 |
| **■ 입력** | | |
| 크롭 | **얼굴 박스** + pad 0.05 → **448** (눈 사이 245px) | **얼굴 박스** → **120** (사전 크롭 배포본) |
| 전처리 | ImageNet 정규화 · RGB | (x−127.5)/128 · **BGR** · 테두리 5px 0 처리 |
| **■ 모델** | | |
| 구조 | 백본 → **점 쿼리 트랜스포머 디코더** | 백본 → **FC 한 층**으로 62-d 회귀 |
| 교사 · 학생 | 교사 **DINOv3 ViT-L/16 310M** · 학생 **ViT-T/16 10.5M** | **MobileNet-V1 3.27M** 단일 (교사·학생 구분 없음) |
| 좌표 정밀화 | 교사: stride 4 **국소 보정** · 학생: stride 4 **히트맵 + 오프셋** | 없음 (파라미터 회귀가 끝) |
| 학습 전용 분기 | — | 68점 회귀 헤드(lrr) · SynergyNet 순환 — **추론 비용 0** |
| **■ 학습** | | |
| 손실 | smooth-L1 + 가시성 (학생은 AWing + 오프셋 L1 추가) | **meta-joint** — VDC / fWPDC 를 스텝마다 골라 쓴다 |
| 증류 | **교사 고정(A)** 로 학생 학습 — 이득 −0.098 로 작다 · 동시 미세조정(B)은 역효과 | 쓰지 않음 |
| 증강 | roll **360°** · 카메라 pitch ±25° / yaw ±15° · 어려운 표본 가중 | 색 · 테두리 · 가림 · 실제 물체 가림 |
| 시간축(영상) | 모델 안에 이전 프레임 주입 → **기각** (지터 2배로 악화) | 짧은 영상 합성(svs) — 추론 평활은 논문이 반대 |
| **■ 평가 지표** | | |
| NME 정규화 | 눈 **바깥꼬리** 거리 (inter-ocular) | GT 랜드마크 bbox 의 √(w·h) |
| 평균 방식 | 전 표본 평균 | **yaw 3구간 평균의 평균** (단순 평균보다 0.4 큼) |
| 지표의 한계 | 규약마다 정규화가 달라 **표끼리 비교 불가** | **NME 는 사실상 자세 지표** — 3D 형상은 거의 안 잰다 |
| 잡음 폭 | 미세조정 아암 흔들림 **±0.03** | seed 3점 **2σ ±0.106** (AFLW ±0.210) |
| **■ 무엇이 들었나 (실측)** | | |
| 가장 큰 레버 | **얼굴이 차지하는 화소** — 71px → 140px 만으로 −0.79 | **증강 + 순환(synergy)** |
| 안 들은 것 | **백본 크기 0%** · 증강 범위 확대 · WSD 일정 · 시간축 | **백본 교체**(YOLO 계열 2종) · 학습 길이 · 추론 단계 축 8개 |
| flip-TTA | 4.120 → 4.078 (−1.0%, `teacher_v3` 기준) — 작아서 기본값 아님 | **채택** — 3.622 → 3.508 (−0.11) |
| **■ 현재 성적** | | |
| 우리 | 교사 **3.916** · 학생 **4.227** (WFLW) | **3.622** (AFLW2000-3D) · 5.125 (AFLW) |
| 기준선 대비 | 교사·학생 모두 **Peppa 상회** · **D-ViT 3.75 에는 뒤짐** | 배포 3.683 상회 — 단 **잡음 폭(±0.106) 안** |
| 극단 자세 | roll 최악 **3.997** vs Peppa Teacher 124.851 | 60~90° 구간이 가장 약함 · AFLW(실사진·가림) 격차 +0.525 |
| 남은 과제 | D-ViT 와의 격차 0.166 | AFLW 격차 — 원인의 60% 가 **가림** |

## 한 줄씩

- **기준선이 반대다.** FA3D 는 배포 가중치가 있어 같은 자로 바로 잰다. FA2D 는 기반 연구(HRFFA)가
  평가셋을 학습해 쓸 수 없어서, 남의 연구(Peppa · D-ViT)를 기준으로 세웠다.
- **데이터가 반대다.** FA3D 는 합성 63만 장으로 학습 도메인에선 이기고 실사진(AFLW)에서 진다.
  FA2D 는 실사진 3.3만 장이고, 얼굴 해상도와 데이터가 가장 잘 들었다.
- **공통점 하나** — 두 태스크가 따로따로 **"백본을 바꾸거나 키우는 것은 레버가 아니다"** 에 도달했다.
